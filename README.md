🛍️ Mall Customer Segmentation Analyzer

A Machine Learning web application developed using K-Means Clustering to segment mall customers based on their spending behavior and annual income. This project was completed as part of the SkillCraft Technology Machine Learning Internship (Task 2).

📌 Project Overview

The Mall Customer Segmentation Analyzer helps businesses understand customer behavior by grouping customers into different segments based on their purchasing patterns.

This project was implemented in two phases:

📓 Phase 1: Jupyter Notebook Implementation

The complete machine learning workflow was developed and analyzed using Jupyter Notebook.

Activities performed:

Data Collection and Loading
Data Cleaning and Preprocessing
Exploratory Data Analysis (EDA)
Customer Behavior Analysis
Feature Selection
Data Standardization
K-Means Clustering Implementation
Cluster Visualization
Cluster Interpretation and Insights
🌐 Phase 2: Streamlit Web Application

The clustering model and visualizations were transformed into an interactive web application using Streamlit.

The application allows users to:

Explore the dataset
View customer statistics
Analyze customer demographics
Visualize customer segments
Experiment with different numbers of clusters
Understand customer grouping behavior interactively
